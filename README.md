# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator requires three inputs:

* **Principal** – The initial amount of money.
* **Rate** – The annual rate of interest in percentage.
* **Time** – The time period in years.

## Example

If the principal is 1000, the interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Usage

Run the Bash script and enter the principal amount, rate of interest, and time period when prompted.

```bash
bash simple-interest.sh
```
